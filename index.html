HELP

Origin axes: X red, Y green, Z blue. Drag to rotate freely; scroll or pinch to zoom; right-drag to pan. Hover an occupied voxel (nearest voxel if several overlap). Load CSV reads one or more headered 0-based x,y,z files (in any column order), applies optional #RRGGBB colors, and sizes the cube to the overall max. Generated voxels and CSVs without a color column use the selected default color (black initially). Duplicate coordinates keep the first row's color. Parallel shows a side-by-side pair—relax focus beyond the screen to fuse it. Crossed swaps the pair—cross your eyes to fuse it. Anaglyph overlays a red/cyan image for 3D glasses, centered on the full canvas.
